# LocalLift Website

College project (S.Y. B.Tech, I²IT Pune) – single-page website built with plain HTML, CSS and JavaScript.

## How to run
1. Keep the folder structure as it is (index.html, css/, js/, assets/).
2. Double-click `index.html` – it opens in any browser. No installation or internet needed.
   (Optional: in VS Code, use the "Live Server" extension.)

## Files
- `index.html` – all 7 sections: Home, About Us, Services, Target Customers, Pricing, How It Works, Contact Us
- `css/style.css` – colours (CSS variables at the top), layout, hover effects, mobile layout
- `js/script.js` – builds service cards, customer buttons, mobile menu, scroll animation, form validation
- `assets/` – college logo (add your own photos/logo here)
